Save unlocks to GitHub

Your skill tree lives in a private gist on your GitHub account. Every device can read it; to save changes from this device, add a GitHub token once. It is stored on this device encrypted with your dashboard password.

  1. Open GitHub → new classic token (the gist scope is already ticked; pick an expiry).
  2. Click Generate token, copy it, paste it here and save.
